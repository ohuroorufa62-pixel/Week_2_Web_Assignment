# My Budget Tracker

## Project Description

My Budget Tracker is a simple website for organizing and tracking expenses.

The project uses HTML and CSS to create a clean and user-friendly interface.

## Files

### index.html

The `index.html` file contains:

- Main heading
- Budget Tracker logo
- Add Expense form
- Expense name input
- Amount input
- Category dropdown
- Add Expense button
- Expense table
- Sample expense records
- How to use section
- Budgeting tips video

### style.css

The `style.css` file controls the appearance of the website.

It includes:

- Google Fonts
- Color palette
- Heading styles
- Form styling
- Button styling
- Table styling
- Borders
- Padding
- Margins
- Rounded corners
- Card designs
- Hover effects
- Input focus effects

## Color Palette

The project uses a blue and neutral color palette.

- Blue: `#2563eb`
- Dark text: `#1e293b`
- Light background: `#f1f5f9`
- White: `#ffffff`
- Border: `#cbd5e1`

## Typography

Two Google Fonts are used:

- **Poppins** for headings
- **Roboto** for body text, labels, forms, and table content

## CSS Box Model

The project uses:

- `margin` to separate sections
- `padding` to create space inside sections
- `border` to define sections
- `border-radius` to create rounded corners
- `box-shadow` to create a modern card appearance

The header, Add Expense form, and Expense Table are displayed as separate cards.

## Technologies

- HTML5
- CSS3
- Google Fonts

## Future Improvements

JavaScript will be added in future weeks to make the Budget Tracker interactive and allow users to add and calculate expenses.
